I build **real-time voice AI** — the streaming STT → LLM → TTS pipelines behind AI phone agents that answer, understand, and talk back in under a second. These days that means telephony for regulated BFSI (debt-collection) and healthcare, on [LiveKit](https://livekit.io) + SIP.

- 🎙️ **Voice AI Engineer @ Ignosis AI** — building a real-time voice platform for BFSI telephony on LiveKit SIP (Exotel/Vobiz trunks), targeting **sub-700 ms** end-to-end latency with full barge-in handling, provider failover, and an offline eval harness (WER + LLM-as-judge) that replays production calls to catch regressions before users do.
- 🏥 **Previously @ Core Cognitics** — co-led a multi-tenant voice AI platform on the LiveKit Agents SDK handling **10k+ calls/day** across healthcare & automotive; multilingual (Arabic / Indic / European) with mid-call provider switching, a multi-layer guardrail system, MCP tool servers, and a RAG stack on Qdrant.
- 🐛 Found and reported a bug in the [LiveKit Agents SDK (#5665)](https://github.com/livekit/agents/issues/5665).
- ⚡ Run production observability with OpenTelemetry → Langfuse / Grafana / Prometheus on Kubernetes & AWS ECS.

> I have a healthy obsession with latency budgets and a slightly less healthy one with finishing side projects. 😄
